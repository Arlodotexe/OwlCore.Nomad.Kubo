## **Transports Usage**

### Internet
- WAN built into Kubo, including p2p NAT traversal

### Intranet
- LAN built into Kubo (tcp, udp, quic, websockets, etc.)
- Bluetooth, WiFi Direct, LoRA not built into Kubo
